Performance & competitive audit

Is the new page actually fast — and how does it compare to dr-brace.com?

Daniel flagged conversion as the priority, and page speed is one of the few levers with hard evidence behind it: Google's own research puts each extra second of mobile load time at roughly a 20% drop in conversions. So instead of general advice, here are real Lighthouse measurements from both live properties, what's actually causing the gap, and what we already fixed on ComfyNap today.

A 3.7MB video loads from a staging URL

The single heaviest file on the page streams from shopifypreview.com — a leftover preview/staging link, not their production CDN. Looks like a forgotten edit that never got pointed at the live file.

Google's tag loads four times

gtag.js for both a GA4 property and a Google Ads account each load twice (with and without a gtm= parameter) — about 700KB for what should be one request. Likely double-counting conversions too.

Built with a visual page builder

PageFly generates the whole layout — 101 script tags, 256 nested <div>s, 260KB of inline CSS/JS. Flexible for non-developers, but every section pays a markup tax a hand-built page doesn't.

What we already fixed on ComfyNap today

Two changes, both shipped in this build — not a proposal, already measured before and after.

Fix 1
Self-hosted the two brand fonts

Google Fonts was a render-blocking request on a different domain, delaying first paint by ~840ms in testing. The two fonts now ship from our own server instead.

78/100→92/100
Fix 2
Hero gallery loads on demand

All six gallery photos sat stacked in the same box, so the browser fetched every one immediately. Now five of six load only when a visitor actually opens them.

721 KB→549 KB

Recommended order

Now
Get real reviews on the page

The comparison table above shows reviews as Dr. Brace's biggest proof-of-trust advantage. This is content, not code — send us real reviews (or approve importing the Amazon ones) and we wire in Judge.me at the same time as the Shopify migration.

Now
Push ComfyNap's LCP under 2.5s

92/100 is good, but the hero image itself is still the slowest link. Once on Shopify's CDN (which serves over HTTP/2 with edge caching) this likely closes most of the remaining gap on its own — worth re-measuring after launch before doing more work here.

Next
Add a quantity discount

"Buy 2, save X%" is a proven average-order-value lever and Dr. Brace already validated it works for this audience. Cheap to add as a native Shopify variant, no new app required.

Next
Fix Dr. Brace's four issues above

Independent of ComfyNap: swapping that one video for a compressed, self-hosted file and removing the duplicate Google tags would likely take Dr. Brace from "Poor" to "Good" without touching a single conversion feature.

Later
Live chat and financing

Both proven, both add a render-blocking-capable third-party script. Worth it once there's traffic to justify the app cost and support load — not before.

Later
Personalization (Visually.io)

Powerful once you have enough Meta/Google traffic segments to personalize against. At current volume it's mostly added weight for no measurable lift — revisit once ad spend scales.
